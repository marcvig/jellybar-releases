# JellyBar Releases

Public release assets for [JellyBar](https://jellybar.app) — a reliable menu bar icon manager for macOS.

- **Sparkle appcast:** `https://marcvig.github.io/jellybar-releases/appcast.xml`
- **Install via Homebrew:** `brew install --cask marcvig/tap/jellybar`

Download the latest DMG from [Releases](https://github.com/marcvig/jellybar-releases/releases).
